# 🐍 Snake Game

🎮 Play the game here:  
👉 https://raysankha2005.github.io/Snake-game/

## 🚀 Features
- Classic snake gameplay
- Score & High Score (saved using LocalStorage)
- Timer system
- Restart button
- Clean UI

---

## 🕹️ Controls
- Arrow Keys to move:
  - ↑ Up
  - ↓ Down
  - ← Left
  - → Right
